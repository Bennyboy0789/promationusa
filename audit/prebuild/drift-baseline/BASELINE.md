## How to use

This is the pre-rebuild baseline of the live site. After the new site launches:

1. Re-run the same extraction (same 22 paths, same desktop-Chrome user agent, curl + HTML parse) against the launched site and write a `post-launch.json` with the identical field set.
2. Diff against `baseline.json` per path: HTTP status, title, meta description, meta robots, canonical, viewport, H1s, first-5 H2s, JSON-LD count/types, og:title, og:image, and word count (allow ~10-15% word-count variance; flag larger drops as possible content loss).
3. Also diff `robots.txt.snapshot` and `sitemap-urls.txt` against the new site's robots.txt and sitemap URL list — every baseline URL missing from the new sitemap needs either a page or a 301.
4. Treat as regressions: 200 -> non-200, lost/changed titles or meta descriptions, canonical pointing to the wrong URL, missing H1s, dropped JSON-LD types, and large word-count decreases. Note: `/et8484-dispensing-robot` was already 404 at baseline capture.
